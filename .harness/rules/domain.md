# Domain Rules

- 核磁共振上位机必须按“连接 -> 配置 -> 预检 -> 扫描 -> 保存 -> 分析”的顺序组织核心流程。
- 科研与教学场景应优先暴露模板化流程，而不是把底层 DLL 参数直接堆给用户。
- 扫描、异常、更新和通道状态必须可见，至少要能看到连接状态、扫描状态、温度、异常位和采集结果指标。
- 原型和文档不得暗示临床诊断能力，当前阶段只覆盖科研与教学。
- 首屏推荐条件只能是“一级场景 + 检测对象”，序列和参数属于任务模板内部。
- 一级场景按主要科研结果分类，不按动物、植物、食品等对象行业分类。
- 未完成设备适配的协议和参数必须标记“待设备适配”，不得描述为已验证参数。
- 设备连接和采集验收完成前，真实 `Run()` 必须保持 HOLD。
- 已跑通基础序列在未核验前只能称为 `FSE A` 和 `FSE B`，不得直接命名为 T1 或 T2。
- 血管分割、脂肪/水分/油分定量、糖度预测和 fMRI 统计属于外部分析软件范围，控制台只负责图像获得、QC 和交接。
- 0.17 T 参数预设必须显示 `presetVersion=2`，并在实机验证前保持“开发预设 / 待设备适配”状态。
- `FSE A / FSE B` 的目标矩阵只能作为目标重建矩阵，不能直接写入 SDK 底层 `noSamples / noViews`。
- `FSE A / FSE B` 的 `12.9 ms` 只能标记为“序列标称 TE”，核对回波列与 k 空间排序前不得写成“有效 TE”。
- 任何参数导出、报告或交接包都必须携带参数版本、适配状态、Run 状态和未回填字段清单。
- 参数预设中涉及真实最短 TE、梯度爬升、RF 功率、均匀成像区和 SDK 字段映射的内容，必须等待实机和当前序列回填。
