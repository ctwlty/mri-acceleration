# Plan

## UX Change

将左侧三段大列表改成紧凑筛选器：

- `一级场景`：下拉框，显示场景名称和任务数量。
- `检测对象`：下拉框，随一级场景过滤。
- `模板搜索`：关键词搜索模板名、检测对象、协议、输出类型和采集协议。
- `推荐模板`：只显示筛选后的模板结果列表。

## Scale Strategy For Many Scenarios

当模板从几十个增加到上百个时，推荐演进路径：

1. 保持首屏只暴露一级场景和对象，不把序列参数作为筛选入口。
2. 增加搜索、标签和最近使用，避免用户从全量树里找任务。
3. 给模板增加元数据：对象类别、样品尺寸、活体/离体、输出类型、协议能力、验证状态、适配状态。
4. 模板列表使用“推荐排序”：已验证 > 适配中 > 探索性；最近使用和收藏靠前。
5. 后续改为 `QAbstractItemModel + QSortFilterProxyModel`，支持大模板库过滤和排序。
