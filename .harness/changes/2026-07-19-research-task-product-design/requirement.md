# Requirement

## User Request

基于新的科研任务逻辑优化产品设计。首屏不再要求用户理解序列和参数，而是从“一级场景 + 检测对象”推荐任务模板，再展开实验链、完成图像质控和结果交接。

## Success Criteria

- 明确四类一级场景的产品定义。
- 明确检测对象和任务模板的关系。
- 设计首屏推荐、模板详情、实验执行、图像质控、结果交接的页面结构。
- 保留当前边界：外部分析软件完成高级分析，真实 `Run()` 继续 HOLD，参数标记“待设备适配”。
- 输出可指导下一轮客户端 UI 开发的产品设计文档。

## Out Of Scope

- 不实现代码。
- 不补真实设备参数。
- 不执行真实 `Run()`。
- 不把 FSE A/B 未核验前命名为 T1/T2。
- 不承诺脂肪、水分、糖度或 fMRI 统计由控制台直接完成。
