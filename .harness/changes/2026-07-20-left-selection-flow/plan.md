# Plan

## UX Direction

左侧从单个混合模板列表改为三段式任务选择器：

1. `一级场景`：展示四类科研目标，并显示该场景下任务数量。
2. `检测对象`：根据一级场景过滤对象。
3. `推荐模板`：根据场景和对象显示匹配模板。

选择区域放入独立滚动容器，底部 SDK / 建链 / Demo 采集等按钮固定在左侧底部，避免不同窗口高度下互相重叠。

## Implementation Steps

- 扩展 `MainWindow` 状态，增加一级场景列表和检测对象列表。
- 增加场景、对象、模板三级联动函数。
- 将模板索引保存到 `QListWidgetItem::UserRole`，保证筛选后仍能正确应用原始模板。
- 调整 QSS，使三类列表有清晰的视觉层级。

## Acceptance Criteria

- 构建通过。
- 离屏启动不崩溃。
- 左侧不再出现模板摘要与控制按钮重叠。
- 当前模板变化后，中间实验链和右侧参数仍同步刷新。
