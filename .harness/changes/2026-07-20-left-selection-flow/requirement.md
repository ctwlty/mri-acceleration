# Requirement

## User Request

重新整理客户端左侧页面显示逻辑，避免采集模板、场景、对象、Run 状态和按钮相互挤压重叠，让科研用户能清晰选择一级场景与检测对象。

## Success Criteria

- 左侧入口按 `一级场景 -> 检测对象 -> 推荐模板` 三步呈现。
- 左侧不再展示长参数、Run 摘要或模板详情，避免与按钮重叠。
- 一级场景变化后自动筛选检测对象；检测对象变化后自动筛选推荐模板。
- 右侧参数预设仍保持展示用途，不直接写入 SDK。
- Mac Demo 模式可构建并启动。

## Out Of Scope

- 不解除真实 `Run()` 的 HOLD。
- 不把参数预设映射到 SDK 字段。
- 不新增真实设备连接能力。
