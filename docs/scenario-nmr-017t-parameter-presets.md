# Agent MRI 0.17 T 七类科研任务协议与参数预设

版本：`V1.2 Final`  
参数预设版本：`presetVersion=2`  
设备条件：`B0=0.17 T`，当前线圈最大样品包络 `Φ50×70 mm`，最大梯度 `30 mT/m @ 50 A`

## 1. 使用定位

本文件用于把七类科研任务、通用协议和 0.17 T 参数预设写入实验模板。所有数值均为开发预设，不代表设备已经完成实机验证。

产品内必须以以下方式展示：

- 参数状态：`待设备适配`
- Run 状态：`HOLD`
- 序列状态：候选协议 / 开发预设
- 参数版本：`presetVersion=2`

## 2. 参数边界

- `FSE A / FSE B` 中的矩阵是目标重建矩阵。
- SDK 底层 `noSamples / noViews` 等字段必须在获得当前序列映射后回填，不能直接沿用历史高采样规模。
- `FSE A / FSE B` 的 `12.9 ms` 保留为历史序列标称 TE。
- 在核对回波列与 k 空间排序前，`12.9 ms` 不得改写为“有效 TE”。
- 实际最短 TE、梯度爬升、RF 功率、均匀成像区和底层 SDK 字段仍需当前序列与实机回填。

## 3. 模板集成方式

每个任务模板增加一个参数预设区：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `presetVersion` | `2` | 参数预设版本 |
| `fieldStrength` | `0.17 T` | 主磁场 |
| `sampleEnvelope` | `Φ50×70 mm` | 当前线圈最大样品包络 |
| `gradientLimit` | `30 mT/m @ 50 A` | 最大梯度边界 |
| `protocols` | `LOC_017T`, `FSE_A_017T` | 模板包含的候选协议 |
| `parameterStatus` | `待设备适配` | 是否已完成实机验证 |
| `runGate` | `HOLD` | 是否允许真实采集 |
| `sdkMappingStatus` | `待序列字段映射` | SDK 参数字段是否已回填 |
| `physicsCheckStatus` | `通过开发边界检查` | 是否超过已知物理边界 |

UI 展示建议：

- 任务模板卡片只展示协议别名、适配状态和 Run 状态，不展示完整参数表。
- 模板详情页提供“参数预设”抽屉。
- 参数抽屉顶部固定显示“开发预设，未完成实机验证”。
- 任何导出报告必须带 `presetVersion=2` 和 `待设备适配` 标记。

## 5. 物理检查结论

上述回波时间顺序、层面覆盖、水脂相位步进、CPMG 末回波时间和 DWI 理想梯度幅值均未超过已知物理边界；所有梯度候选均低于 `30 mT/m / 50 A`。

该结论只代表开发预设层面的物理边界检查，不代表实机验证通过。

## 6. 后续回填清单

- 当前序列到 SDK 字段的映射。
- `noSamples / noViews` 等底层字段。

- 均匀成像区和线圈装样约束。
- 标准模体 QC 阈值。
- 每个模板是否解除 `Run HOLD` 的验收证据。
