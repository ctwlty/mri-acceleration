# 09 FSE A Mock 执行

## 目的与边界

显示当前唯一 Mock run 的确定性执行进度，并提供暂停、继续和取消。不得生成真实 RAW，不得自动启动第二次运行。

## 进入与离开

- 进入：只能由 08 合法开始动作进入，状态为 Running。
- 自动前进 10：Mock 执行完成后进入 Processing。
- 返回/取消：取消当前 run，保留身份和审计，返回 08 或 12 的取消摘要；不能显示成功。
- 直接 `--mock-step 9` 仅能显示 Empty/设计 QA，不得伪造 Running。

## 信息层级与数据来源

1. 当前 run ID、snapshot ID、`dataSource=MOCK`。
2. FSE A Mock 进度和状态；来源为 `MockWorkflow`。
3. 当前 Mock 资产预览；标记为执行示例，不是实时设备图。
4. 右栏：当前阶段、暂停/取消状态；Live HOLD。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 暂停/继续 / `MockPauseButton` | Running 或 Paused | 状态在 Paused/Running 切换，进度停/续 | 其他状态 disabled |
| 取消 Mock / `LeftMockStopButton` | Running 或 Paused | 先显示确认；确认后 Cancelled，停止计时 | 撤销确认则继续原状态 |
| 左栏开始 / `LeftMockStartButton` | 当前 run 活动 | disabled 并显示当前 run ID | 防止重复 Run |
| 持久返回 / `WorkflowBackButton` | Running/Paused | 等价于请求取消，不可静默回退 | 必须确认 |
| 持久下一步 / `WorkflowNextButton` | Running/Paused | disabled，说明等待完成；不允许跳过 | 完成由模型自动进入 10 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 进入 Running 前短暂准备，进度 0，无图/QC |
| Empty | 无合法 run，显示“尚未开始”，不显示 64% 等固定成功状态 |
| Ready | 本页不使用静态 Ready；合法活动态为 Running/Paused |
| Warning | Paused 或取消确认中 |
| Error | 执行模型失败，状态 Failed，无图/QC，可返回修正 |
| Disconnected | Live 区显示未连接；Mock 不转为设备错误 |
| Permission denied | 输出权限在 08 已阻塞；运行中发现权限变化则 Failed |

## 导航、持久化与审计

- run ID/snapshot ID 在暂停、继续和取消后不变。
- Cancelled 保留审计但不得生成 `standard-mock-result.png`、QC 或完整包。
- 审计：`MOCK_RUN_PROGRESS`、`MOCK_RUN_PAUSED`、`MOCK_RUN_RESUMED`、`MOCK_RUN_CANCELLED`、`MOCK_RUN_COMPLETED`。

## 可访问性

- 进度条提供百分比和状态文本。
- 暂停/继续按钮文本随状态改变。
- 取消确认可由键盘完成并默认聚焦安全选项。
