# 13 历史记录（按需）

## 目的与边界

只读浏览实际封存的 Mock 结果包，按样品、模板、日期、run ID 或关键词筛选，并查看来源记录。不得显示硬编码 Mock-01/Mock-02 或未生成样例。

## 进入与离开

- 进入：12 点击历史且结果根至少存在一个有效或可报告损坏的 manifest。
- 返回 12：`BackToResultsButton` 或持久返回。
- 13 不属于主流程下一步；没有指向 14 的动作。

## 信息层级与数据来源

1. 表格行：扫描结果根目录并解析实际 `manifest.json`。
2. 选中摘要：run ID、snapshot ID、样品、模板、包状态、QC、来源和绝对路径。
3. 预览图：只从选中包的 `standard-mock-result.png` 读取；校验失败不显示。
4. Warning/Error 包保留可见状态但不冒充完整。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 样品筛选 / `HistorySampleFilter` | 有历史行 | 表格按实际样品过滤 | 无行时保留 Empty |
| 模板筛选 / `HistoryTemplateFilter` | 有历史行 | 表格按模板过滤 | 同上 |
| 日期筛选 / `HistoryDateFilter` | 有历史行 | 表格按 manifest 时间过滤 | 同上 |
| 关键词 / `HistoryFilter` | 有历史行 | 同时匹配 run ID、snapshot ID、样品、模板和路径 | 清空恢复 |
| 历史表 / `HistoryReadOnlyTable` | 有实际行 | 选中后右栏摘要和预览更新 | 禁止编辑 |
| 打开结果 / `HistoryOpenButton` | 选中有效包且目录存在 | 打开精确结果目录 | 损坏/无选择时 disabled 并解释 |
| 对比参考 / `HistoryCompareButton` | 任意 | 不可点击 | 始终 disabled，原因“v0.1 单选只读历史不支持对比”，不得用日志冒充对比 |
| 来源记录 / `HistorySourceButton` | 选中有效或 Warning 包 | 展示 manifest 来源和校验详情 | 无选择时 disabled |
| 返回结果 / `BackToResultsButton` | Ready/Empty/Error | 进入 12 | 不修改历史 |
| 持久返回 / `WorkflowBackButton` | Ready/Empty/Error | 进入 12 | 与页面返回一致 |
| 持久下一步 / `WorkflowNextButton` | 任意 | 不可用 | hidden 或 disabled，说明历史为终点 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 扫描 manifest，筛选和行操作 disabled |
| Empty | 明确“尚无已封存 Mock 结果包”，表格 0 行，无预览/QC |
| Ready | 实际行可筛选和选择 |
| Warning | manifest 可读但工件缺失/哈希不符，行标 Warning |
| Error | 根目录不可读或 manifest 无法解析，显示路径和原因 |
| Disconnected | Live 设备状态与历史无关，仍保持 BLOCKED 提示 |
| Permission denied | 根目录不可读，显示权限错误且不展示缓存样例 |

## 导航、持久化与审计

- 历史页自身只读；不修改包、manifest 或 QC。
- 审计：`HISTORY_LOADED`、`HISTORY_FILTERED`、`HISTORY_RECORD_SELECTED`、`HISTORY_SOURCE_VIEWED`、`HISTORY_RETURNED`。

## 可访问性

- 表格表头、行状态和选择摘要可由屏幕阅读器读取。
- Warning/Error 不只靠行颜色。
- 空态仍可通过键盘到达返回按钮。
