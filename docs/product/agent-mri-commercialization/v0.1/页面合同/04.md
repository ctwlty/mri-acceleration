# 04 样品登记与准备预检

## 目的与边界

确认固定的 Mock 水模预设，并查看准备检查边界。真实线圈、摆位、设备连接和安全状态没有设备证据时必须显示“待现场确认/Live BLOCKED”。

## 进入与离开

- 进入：03 已采用支持模板。
- 返回 03：`PreparationBackButton` 或持久返回。
- 前进 05：确认固定 Mock 水模预设后点击 `SavePreparationButton` 或持久下一步。
- 本页不调用真实预检，不读取设备温度或 ScanStatus。

## 信息层级与数据来源

1. 样品 ID 与类型：只读 Mock 预设 `WATER-PHANTOM-001 / 标准水模`，来源为本版本合同。
2. Mock 准备项：只读说明；本页不提供线圈或结果根目录编辑器。
3. Live 项：线圈实物、摆位、安全、设备连接均来自门禁合同并保持未证实。
4. 右栏：Mock 可继续与 Live BLOCKED 分开展示。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 返回模板 / `PreparationBackButton` | Ready | 进入 03 | 草稿保留到本次任务内 |
| 确认 Mock 预设并继续 / `SavePreparationButton` | 固定预设可读 | 进入 05，记录 `WATER-PHANTOM-001` 已确认 | 不写真实设备、参数文件或独立样品文件 |
| 真实预检 / `RealPrecheckButton` | 任意 | 不可点击 | disabled；显示未连接、未确认线圈/摆位/安全 |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 03 | 与页面返回一致 |
| 持久下一步 / `WorkflowNextButton` | 固定预设可读 | 代理 `SavePreparationButton` 进入 05 | 与确认按钮共用动作 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 固定 Mock 预设载入中，继续 disabled |
| Empty | 预设不可用，不显示样品已确认 |
| Ready | 固定 Mock 水模预设可确认，Live 仍 BLOCKED |
| Warning | 现场项未证实，逐项说明 |
| Error | 预设字段缺失，显示错误文本并返回 03 |
| Disconnected | 设备连接项显示未连接，不能标绿 |
| Permission denied | 本页不写盘；最终封存权限在 08/12 独立检查 |

## 导航、持久化与审计

- 固定预设确认仅驻留内存，08 冻结后进入 snapshot。
- 审计：`MOCK_SAMPLE_PRESET_CONFIRMED`、`MOCK_PREPARATION_ACKNOWLEDGED`、`PAGE_ENTERED`。
- 不记录“真实预检通过”事件。

## 可访问性

- 每项只读状态有名称、结果和来源文本。
- 未证实项不能只用灰色或空图标表达。
- 预设载入失败时焦点移到返回按钮。
