# 01 进入系统与状态

## 目的与边界

让操作者在任何任务数据出现前确认：当前是 `MOCK` 产品演示、真实设备为 `LIVE: BLOCKED`、存储根目录尚未因运行而写入。页面不得显示重建图、QC 数值或历史样例。

## 进入与离开

- 进入：应用无参数启动；工作流状态为 `Empty`，数据源默认为 `Mock`。
- 离开到 02：点击 `BeginResearchButton` 或持久“下一步”；结果为显示场景/对象选择。
- 不允许：从 01 直接进入 03–13、启动处理、封存结果或触发 Live。

## 信息层级与数据来源

1. 标题栏：固定“场景化核磁共振控制台”。
2. 中栏：入口说明、`MOCK` 数据源、任务尚未创建。
3. 左栏：场景/对象/模板为空，控制方式固定 Mock。
4. 右栏：SDK、设备、真实 Run 为 `BLOCKED`；来源为产品门禁合同，不是设备回报。

## 可交互控件

| 控件 / objectName | 前置条件 | 点击或改变结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 开始科研任务 / `BeginResearchButton` | 页面 Ready | 进入 02，记录 `PAGE_ENTERED:02` | 无二次确认；返回 01 可撤销尚未冻结的选择 |
| 一级场景 / `PrimarySceneCombo` | 用户展开选择 | 更新检测对象候选和推荐模板 | 空选择合法，不生成默认成功数据 |
| 检测对象 / `TargetCombo` | 已选择一级场景 | 更新模板候选 | 未选场景时 disabled 或无候选，并解释 |
| 模板搜索 / `TemplateSearchEdit` | 始终可编辑 | 只过滤实际模板列表 | 清空恢复当前场景候选 |
| 推荐模板 / `TemplateList` | 有候选 | 更新模板摘要，不自动离页 | 空态项不可选择 |
| 使用所选模板 / `UseSelectedTemplateButton` | 选中支持的水模横断位模板 | 进入 03 | 未选或不支持时 disabled，并显示“仅供浏览/未选择” |
| DRY_RUN / `DryRunButton` | 有可冻结草稿 | 显示 Mock 快照预览，明确未写 SDK | 无草稿时 disabled 并解释 |
| Live 相关按钮 | 任意 | 不可点击 | disabled，统一显示 `LIVE: BLOCKED` 和缺失门禁 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 模板目录加载提示；主 CTA disabled；不显示图/QC |
| Empty | 未选场景/对象，模板为空态；不显示图/QC |
| Ready | Mock 入口可用，真实入口 BLOCKED |
| Warning | 选择了仅浏览模板时解释不能进入执行 |
| Error | 模板目录读取失败，显示重试入口和错误文本 |
| Disconnected | 仅在 Live 状态区显示“设备未连接”；不影响 Mock 入口 |
| Permission denied | 结果根目录无权限时显示路径和原因；仍可进入 02，但不能最终封存 |

## 导航、持久化与审计

- 返回：01 无返回动作。
- 下一步：始终在 1280×760 可见；与主 CTA 等价。
- 01 不写结果包；场景草稿仅驻留内存。
- 审计事件：`APP_OPENED`、`DATA_SOURCE_SELECTED`、`PAGE_ENTERED`；均含 UTC 时间和 `dataSource=MOCK`。

## 可访问性

- 主 CTA 可通过 Tab 聚焦并用 Enter/Space 激活。
- 禁用 Live 控件的 accessibleDescription 与 tooltip 均包含阻塞原因。
- 空态、Warning、Error 不只靠颜色表达。
