# 07 定位与切片规划

## 目的与边界

在三标准方位的 Mock LOC 参考图上规划横断位覆盖、中心、切片线和 Read/Phase。更多方位只提供 Mock 自定义斜切提示，不映射真实设备。

## 进入与离开

- 进入：06 Mock LOC Ready。
- 返回 06：持久返回。
- 前进 08：规划有效后点击 `ConfirmLocalizationButton` 或持久下一步。
- `ResearchParametersButton` 返回 05 的 L3 区域；返回 07 后需重新确认定位。

## 信息层级与数据来源

1. 主画布：`LocalizationPlannerView`，来源为合法 Mock LOC 资产。
2. 三标准方位：横断、冠状、矢状；默认横断。
3. 覆盖框、中心、切片线、层厚、层间距、层数、层组位置和 Read/Phase：由当前规划草稿产生。
4. 右栏：规划数值、修改状态和 Live 映射 BLOCKED。

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | LOC 资产加载中，画布和确认 disabled |
| Empty | 无 LOC，不显示覆盖框或伪造规划 |
| Ready | 横断位规划有效，确认可用 |
| Warning | 非横断或自定义斜切仅 Mock；真实映射未知 |
| Error | 图像/规划数据失败，显示返回和恢复推荐 |
| Disconnected | Live 设备未连接，不影响 Mock 拖动 |
| Permission denied | 本页不写盘；资源访问失败按 Error |

## 导航、持久化与审计

- 规划草稿驻留内存，08 冻结；每次修改使旧确认失效。
- 审计：`ORIENTATION_CHANGED`、`READ_PHASE_SWAPPED`、`COVERAGE_CHANGED`、`PLANNING_RESET`、`LOCALIZATION_CONFIRMED`。

## 可访问性

- 画布支持键盘方向键移动中心、Ctrl+上下键移动活动切片；拖动值同时有文本摘要。
- 当前方位、Read/Phase 和修改状态不只靠颜色。
- 所有按钮具有唯一 objectName 和可读 accessibleName。
