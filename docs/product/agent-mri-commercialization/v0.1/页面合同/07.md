# 07 定位与切片规划

## 目的与边界

在三标准方位的 Mock LOC 参考图上规划横断位覆盖、中心、切片线和 Read/Phase。更多方位只提供 Mock 自定义斜切提示，不映射真实设备。

## 进入与离开

- 进入：06 Mock LOC Ready。
- 返回 06：持久返回。
- 前进 08：规划有效后点击 `ConfirmLocalizationButton` 或持久下一步。
- `ResearchParametersButton` 返回 05 的 L3 区域；返回 07 后需重新确认定位。

## 信息层级与数据来源

1. 主画布：`LocalizationPlannerView`，来源为合法 Mock LOC 资产。
2. 三标准方位：横断、冠状、矢状；默认横断。
3. 覆盖框、中心、切片线、Read/Phase：由当前规划草稿产生。
4. 右栏：规划数值、修改状态和 Live 映射 BLOCKED。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 定位画布 / `LocalizationPlannerView` | Mock LOC Ready | 拖动覆盖/中心/切片线并重绘，摘要更新 | 无 LOC 时 disabled |
| 横断 / `OrientationAxialButton` | Ready | 选择横断并更新画布/摘要 | 默认选择 |
| 冠状 / `OrientationCoronalButton` | Ready | 选择冠状并更新 | 进入 08 前必须再次明确横断主路径 |
| 矢状 / `OrientationSagittalButton` | Ready | 选择矢状并更新 | 同上 |
| 交换 Read/Phase / `ReadPhaseSwapButton` | Ready | 轴标和摘要同步变化 | 可再次点击撤销 |
| 自动调整 / `AutoPlanningButton` | Ready | 覆盖框变更，标记已修改 | 可用恢复推荐撤销 |
| 恢复推荐 / `ResetPlanningButton` | Ready | 恢复初始横断位规划 | 清除已修改标记 |
| 更多方位 / `MoreOrientationButton` | Ready | 显示“自定义斜切仅 Mock 规划”说明 | 本版本不新增独立页面 |
| 成像目标 / `ImagingTargetCombo` | Ready | 选择值在摘要中可见 | 无候选时 disabled |
| 修改目标 / `ModifyImagingTargetButton` | 有目标选择 | 应用到规划草稿并显示反馈 | 无选择时 disabled |
| 科研参数 / `ResearchParametersButton` | Ready | 进入 05 并展开 L3 | 返回后定位确认失效 |
| 确认定位 / `ConfirmLocalizationButton` | 横断位规划有效 | 进入 08 | 非横断主路径时 Warning 并需恢复横断 |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 06 | 不冻结规划 |
| 持久下一步 / `WorkflowNextButton` | 同确认定位门禁 | 进入 08 | 共用门禁 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | LOC 资产加载中，画布和确认 disabled |
| Empty | 无 LOC，不显示覆盖框或伪造规划 |
| Ready | 横断位规划有效，确认可用 |
| Warning | 非横断或自定义斜切仅 Mock；真实映射未知 |
| Error | 图像/规划数据失败，显示返回和恢复推荐 |
| Disconnected | Live 设备未连接，不影响 Mock 拖动 |
| Permission denied | 本页不写盘；资源访问失败按 Error |

## 导航、持久化与审计

- 规划草稿驻留内存，08 冻结；每次修改使旧确认失效。
- 审计：`ORIENTATION_CHANGED`、`READ_PHASE_SWAPPED`、`COVERAGE_CHANGED`、`PLANNING_RESET`、`LOCALIZATION_CONFIRMED`。

## 可访问性

- 画布支持键盘选择标准方位；拖动值同时有文本摘要。
- 当前方位、Read/Phase 和修改状态不只靠颜色。
- 所有按钮具有唯一 objectName 和可读 accessibleName。
