# 08 运行前确认与参数快照

## 目的与边界

冻结本次 Mock 参数快照，完成三项 Mock 运行确认，并明确真实 Run 因七项门禁未满足而 `BLOCKED`。

## 进入与离开

- 进入：07 横断位规划已确认。
- 返回 07：`RunConfirmationBackButton` 或持久返回；返回会使本次确认失效。
- 前进 09：三项 Mock 确认全部勾选后点击 `MockAcquireButton` 或持久下一步。
- 真实 Run 永远不可达。

## 信息层级与数据来源

1. 参数快照：场景、对象、模板、协议链、方向、FOV、矩阵、TR、TE、数据源。
2. 身份：开始时生成的唯一 run ID 与 snapshot ID。
3. Mock 三项确认：来源、输出和不会触发设备。
4. Live 七项门禁：逐项缺失原因。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 确认项 / `RunConfirmationCheck1..3` | 快照可冻结 | 勾选状态与 Mock 开始门同步 | 任一取消立即禁用开始 |
| 返回调整定位 / `RunConfirmationBackButton` | Ready | 进入 07，清空确认 | snapshot 草稿可重建 |
| 开始 Mock / `MockAcquireButton` | 三项全选、Mock、支持模板 | 生成唯一身份、冻结 snapshot、进入 09 | 未满足时 disabled 并显示缺失项 |
| 左栏开始 / `LeftMockStartButton` | 同上 | 代理同一开始动作 | 不得绕过确认 |
| 真实 Run / `WorkflowRealRunButton`、`RealRunButton` | 任意 | 不可点击 | disabled；列出七项 Live 缺失 |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 07并清空确认 | 与页面返回一致 |
| 持久下一步 / `WorkflowNextButton` | 同 Mock 开始门禁 | 开始同一次 Mock | 与 MockAcquire 共用动作，防重复 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 快照冻结中，所有开始动作 disabled |
| Empty | 无有效草稿时不显示 snapshot ID |
| Ready | 快照预览完整，等待确认 |
| Warning | 确认未全或 Live 门禁缺失 |
| Error | 快照字段不完整，列出字段并返回 05/07 |
| Disconnected | Live 门禁明确设备未连接 |
| Permission denied | 输出根不可写时 Mock 开始也 blocked，并显示路径 |

## 导航、持久化与审计

- 点击开始的单一事务生成 run ID、snapshot ID 并冻结快照。
- 离开 08、修改目录/参数/规划后确认全部失效。
- 审计：`RUN_CONFIRMATION_CHANGED`、`SNAPSHOT_FROZEN`、`MOCK_RUN_STARTED`、`LIVE_BLOCKED_VIEWED`。

## 可访问性

- 三项确认有独立 label，Tab 顺序后接 Mock 开始。
- disabled 开始按钮通过相邻状态条和 tooltip 给出原因。
- 快照键值可由屏幕阅读器按顺序读取。
