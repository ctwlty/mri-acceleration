# 02 选择场景与检测对象

## 目的与边界

选择“水模 → 横断位”任务语义，并明确默认候选为 LOC→FSE A。此页只形成草稿，不生成 run ID、snapshot、图像或 QC。

## 进入与离开

- 进入：01 点击开始；数据源为 Mock。
- 返回 01：`SceneSelectionBackButton` 或持久返回。
- 前进 03：选择主候选后点击 `ShowRecommendedTemplateButton` 或持久下一步。
- 不支持的科研目录可浏览，但不能进入 Mock 执行主路径。

## 信息层级与数据来源

1. 中栏主内容：场景、对象、模板推荐理由。
2. 默认候选：水模横断位、LOC→FSE A；来源为仓库 `SceneCatalog` 与 v0.1 合同。
3. FSE B 仅在 03 用户主动添加后出现。
4. 右栏：当前草稿摘要和 `MOCK` 标记。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 一级场景 / `PrimarySceneCombo` | Ready | 对象和模板候选更新 | 无匹配时显示 Empty |
| 检测对象 / `TargetCombo` | 已选场景 | 推荐列表更新 | 无对象时 disabled 并解释 |
| 模板搜索 / `TemplateSearchEdit` | Ready | 列表实时过滤 | 清空恢复 |
| 推荐模板 / `TemplateList` | 有实际候选 | 左栏摘要和是否可继续更新 | 不支持项标“仅供浏览” |
| 默认候选 / `PrimaryTemplateRecommendationRadio` | Ready | 卡片选中态、下一步文案更新 | 与重复模板互斥 |
| 重复模板 / `RepeatTemplateRecommendationRadio` | 候选存在 | 卡片选中态更新 | 若不纳入 v0.1 执行，下一步说明仅浏览 |
| 返回 / `SceneSelectionBackButton` | Ready | 进入 01 | 撤销未冻结草稿 |
| 查看推荐模板 / `ShowRecommendedTemplateButton` | 支持的候选已选 | 进入 03 | 未选/不支持时 disabled 并显示原因 |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 01 | 与页面返回一致 |
| 持久下一步 / `WorkflowNextButton` | 支持候选已选 | 进入 03 | 与主按钮共用门禁 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 推荐计算中，继续 disabled |
| Empty | 无场景/对象/模板；无图/QC |
| Ready | 支持候选选中，可继续 |
| Warning | 候选仅供浏览或筛选无结果 |
| Error | 目录数据不一致，显示重试并阻止继续 |
| Disconnected | Live 区显示未连接；Mock 选择仍可用 |
| Permission denied | 不涉及写入；若全局结果根不可写，仅显示后续封存 Warning |

## 导航、持久化与审计

- 返回和下一步必须在常用窗口尺寸可见。
- 场景草稿驻留内存；回到 01 可重新选择，未生成磁盘记录。
- 审计：`SCENE_SELECTED`、`OBJECT_SELECTED`、`TEMPLATE_CANDIDATE_SELECTED`、`PAGE_ENTERED`。

## 可访问性

- 单选组有可读组名，互斥关系可由键盘理解。
- 卡片不是按钮；真实动作只由命名控件承担。
- Warning 文案包含文字标识，不只使用橙色。
