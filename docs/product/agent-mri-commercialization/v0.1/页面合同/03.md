# 03 确认推荐任务模板

## 目的与边界

确认 v0.1 的默认协议链、预期处理和 QC 边界。默认只包含 LOC→FSE A；FSE B 只有用户主动添加才进入草稿。

## 进入与离开

- 进入：02 已选择支持的水模横断位候选。
- 返回 02：`TemplateBackButton` 或持久返回。
- 前进 04：`AcceptTemplateButton` 或持久下一步。
- 更换左栏为不支持模板时回到 02，不保留误导性的成功状态。

## 信息层级与数据来源

1. 模板名称、目标与默认协议链；来源为实际 `SceneCatalog` 条目。
2. 模板能力：LOC、FSE A、Mock 处理、图像级 QC。
3. 右栏：草稿状态、Mock 来源和真实设备 BLOCKED。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 添加 FSE B 对照 / `AddComparisonButton` | FSE B 尚未添加 | 协议链立即出现 FSE B，按钮变为已添加/disabled | 返回 02 或重新选模板可撤销 |
| 返回推荐列表 / `TemplateBackButton` | Ready | 进入 02 | 不冻结模板 |
| 采用模板并继续 / `AcceptTemplateButton` | 支持模板且数据源 Mock | 进入 04 | 不支持时 disabled 并解释 |
| 使用所选模板 / `UseSelectedTemplateButton` | 左栏支持模板 | 保持/进入 03并刷新摘要 | 采集中 disabled |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 02 | 与页面返回一致 |
| 持久下一步 / `WorkflowNextButton` | 模板可采用 | 进入 04 | 与采用按钮共用门禁 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 模板详情加载中，继续 disabled |
| Empty | 无有效模板，不显示协议成功状态 |
| Ready | 默认 LOC→FSE A 可确认 |
| Warning | FSE B 已加入时提示会增加 Mock 路径内容；不暗示真实扫描 |
| Error | 模板字段缺失时阻止继续并列字段 |
| Disconnected | 真实设备未连接仅影响 Live |
| Permission denied | 本页不写盘；全局输出权限问题只作后续 Warning |

## 导航、持久化与审计

- 模板草稿与 FSE B 标志驻留内存，直到 08 冻结 snapshot。
- 审计：`TEMPLATE_ACCEPTED`、`COMPARISON_ADDED`、`DRAFT_CHANGED`、`PAGE_ENTERED`。

## 可访问性

- 协议链用文本表达，不只依赖连线或颜色。
- 添加对照后的状态变化通过按钮文本和状态摘要同时表达。
