# 06 LOC Mock 规划参考

## 目的与边界

展示合法 Mock LOC 参考资产，为 07 规划提供视觉来源。该页是运行前准备，不执行 Mock run、不生成进度、run ID、snapshot ID 或真实 RAW。

## 进入与离开

- 进入：05 参数草稿合法并确认继续。
- 返回 05：持久返回。
- 前进 07：参考资产可读后点击 `OpenLocalizationPlanningButton` 或持久下一步。
- 直接 `--mock-step 6` 只能用于设计 QA，必须显示“规划参考，尚未开始本次 Mock”。

## 信息层级与数据来源

1. Mock LOC 图：项目合法资源，显式标记“`MOCK` 规划参考，非本次运行产物”。
2. 运行进度：本页不显示采集进度；本次 Mock 仅在 08 冻结快照后开始。
3. 三方位缩略图：项目资源，只作为规划参考。
4. 右栏：Mock 阶段状态；Live Run 仍 BLOCKED。

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 参考资产载入中；下一步 disabled |
| Empty | 无参考图，仅显示“Mock LOC 参考资产不可用” |
| Ready | Mock LOC 参考资产可见，来源与非运行状态明确 |
| Warning | 资产为设计 Mock，不代表真实定位像 |
| Error | 资源不可读时无图，显示错误和返回 05 |
| Disconnected | Live 未连接状态独立显示 |
| Permission denied | 不写盘；资源读取权限失败按 Error 处理 |
