# 11 标准 Mock 结果与 QC 确认

## 目的与边界

展示当前 run 的标准 Mock 重建图，并在图像实际可读后计算图像级 QC。QC 是软件提示，科研结论由人确认。

## 进入与离开

- 进入：10 已进入 Reconstructed。
- 返回 07：`ReturnToLocalizationButton`，创建后续新 run 草稿；不得覆盖当前 run。
- 前进 12：QC 成功后点击 `ConfirmResultButton`；QC 失败时只能返回或重试。
- 直接打开 11 且没有模型成功状态时显示 Empty。

## 信息层级与数据来源

1. 主图：当前 run 绑定的 `:/mock-reconstruction.png` 处理结果，显式 `MOCK`。
2. QC：由 `ImageQualityEvaluator` 对该图实际计算的 SNR、均匀性和对象尺寸。
3. 不可评估项：重复稳定性明确需要多次运行，不给伪造数值。
4. 右栏：run ID、来源、QC 状态和科研用户确认边界。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 返回定位/新运行 / `ReturnToLocalizationButton` | Reconstructed/QcReady | 保留当前 run，回 07创建新草稿 | 不覆盖当前结果 |
| 重试 QC / `RetryMockQcButton` | QC Error 且源资产可重新读取 | 重新载入同一源资产并计算；成功后再显示图与 QC | Failed 时图/QC 保持为空，不修改 snapshot |
| 确认结果 / `ConfirmResultButton` | QcReady | 记录科研确认，进入 12 | QC 为空/失败时 disabled |
| 持久返回 / `WorkflowBackButton` | Ready | 等价于返回定位的新运行动作 | 明确不覆盖 |
| 持久下一步 / `WorkflowNextButton` | QcReady | 进入 12 | 与确认结果共用门禁 |
| 主图和 QC 卡 | 任意 | 只读 | 不伪装按钮 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | QC 计算中，图可在 Reconstructed 后显示，数值为空 |
| Empty | 无当前成功重建，无图、无 QC 数值 |
| Ready | QcReady，图与计算值绑定同一 run |
| Warning | 科研样品结论需研究者确认；重复稳定不可评估 |
| Error | 图不可读或 QC 失败；图与 QC 均为空，提供重试/返回 |
| Disconnected | Live 未连接不影响 Mock 结果 |
| Permission denied | 本页不写盘；封存权限在 12 处理 |

## 导航、持久化与审计

- 图与 QC 驻留当前 run；12 才封存。
- 审计：`QC_STARTED`、`QC_COMPLETED`、`QC_FAILED`、`RESULT_CONFIRMED`、`NEW_RUN_DRAFT_REQUESTED`。

## 可访问性

- 图像 accessibleDescription 包含 Mock、run ID 和来源。
- QC 值包含名称、值、单位和“图像级估计”。
- Warning 由文字明确表达。
