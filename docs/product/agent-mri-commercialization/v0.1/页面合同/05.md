# 05 扫描方案与参数确认

## 目的与边界

编辑 Mock L2 参数、查看折叠的 L3 科研参数，并形成待冻结的参数草稿。L4 硬件字段不展示、不写 SDK 或 `.par`。

## 进入与离开

- 进入：04 Mock 准备草稿有效。
- 返回 04：持久返回。
- 前进 06：所有 L2 字段通过数值和范围校验后点击 `ContinueProtocolButton` 或持久下一步。
- `ProtocolUseOnceButton` 只确认草稿用途；`ProtocolSaveVersionButton` 本版本不写模板文件。

## 信息层级与数据来源

1. 协议链：LOC→FSE A，按用户选择可含 FSE B。
2. L2：FOV、矩阵、层厚、层间距、NEX 五个当前界面实际字段；来源为用户草稿和 v0.1 Mock 预设。
3. 计算摘要：必须由当前输入重新计算，不能是固定文案。
4. L3：回波链、带宽等科研参数示例；折叠展示。
5. L4：明确隐藏且不可编辑。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| L2 输入 / `ProtocolL2Current0..4` | Ready | 每次输入后校验；有效则更新计算摘要，无效则显示字段错误 | 无效时继续 disabled；恢复合法值解除 |
| 展开 L3 / `ShowL3Button` | Ready | `L3DetailsLabel` 展开/收起，按钮文字同步 | 不修改 snapshot |
| 仅本次使用 / `ProtocolUseOnceButton` | L2 有效 | 状态显示“本次 Mock 草稿，未写 SDK” | 再次编辑使确认失效 |
| 另存为新版本 / `ProtocolSaveVersionButton` | 任意 | 本版本 disabled，原因“模板持久化未纳入 v0.1” | 不允许只弹日志或假称已保存 |
| 确认方案并继续 / `ContinueProtocolButton` | L2 全部有效且用途已确认 | 进入 06 | 无效字段或未确认时 disabled 并解释 |
| DRY_RUN / `DryRunButton` | L2 有效 | 显示将被冻结的 Mock 快照预览 | 不写 SDK/参数文件 |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 04 | 保留草稿 |
| 持久下一步 / `WorkflowNextButton` | 同继续门禁 | 进入 06 | 与主按钮共用门禁 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 预设载入中，输入和继续 disabled |
| Empty | 字段无值，不显示“有效”或计算结果 |
| Ready | 字段合法，计算摘要与当前输入一致 |
| Warning | L3 展开或数值接近批准的 Mock 目标边界 |
| Error | 非数值、FOV 超出 10–100 mm、矩阵超出 16–512、层厚超出 0.1–20 mm、层间距超出 0–20 mm、NEX 超出 1–16 时逐字段显示 |
| Disconnected | Live 未连接不影响 Mock 草稿；真实映射仍 BLOCKED |
| Permission denied | 本页不写文件；“另存版本”因范围而 disabled，不冒充权限失败 |

## 导航、持久化与审计

- L2 仅驻留草稿；08 才冻结 snapshot。
- 审计：`PROTOCOL_DRAFT_CHANGED`、`PROTOCOL_VALIDATED`、`USE_ONCE_CONFIRMED`、`DRY_RUN_PREVIEWED`、`PAGE_ENTERED`。

## 可访问性

- 每个输入有持久 label、单位、有效范围和错误描述。
- 无效字段通过文字和 accessibleDescription 表达，不只用红框。
- L3 折叠按钮具有 expanded 状态。
