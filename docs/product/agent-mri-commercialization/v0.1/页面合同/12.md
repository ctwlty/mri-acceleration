# 12 结果包保存与任务结束

## 目的与边界

把当前 QcReady run 封存为非覆盖、可校验、来源明确的 Mock 结果包，并提供复制/打开路径与历史入口。

## 进入与离开

- 进入：11 当前 run 的 QC 成功并经用户确认。
- 返回 11：持久返回；已封存包不删除、不覆盖。
- 前进 13：只有实际封存成功后 `OpenHistoryButton` 可用。
- 不允许将尚未封存的内存结果显示为完整结果包。

## 信息层级与数据来源

1. 主图与 run/snapshot 身份：来自当前模型。
2. 七项结果包清单：来自实际写盘结果，不使用静态“已包含”。
3. manifest 摘要：`dataSource=MOCK`、softwareCommit、工件校验。
4. 外部分析：未配置，disabled。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 保存结果包 / `SaveResultPackageButton` | QcReady、未封存、输出可写 | 写七项工件，显示绝对路径和校验摘要 | 已封存后 disabled；不可写/冲突显示错误且不覆盖 |
| 打开结果位置 / `OpenResultLocationButton` | 封存成功且目录存在 | Windows 打开该精确目录，状态显示路径 | 未封存时 disabled 并解释 |
| 复制结果路径 / `CopyResultPathButton` | 封存成功 | 剪贴板写入精确绝对路径并显示“已复制” | 未封存时 disabled |
| 外部分析 / `ExternalAnalysisButton` | 无配置 | 不可点击 | disabled，原因“未配置外部分析” |
| 查看历史 / `OpenHistoryButton` | 至少一个有效结果包 | 进入 13并加载实际 manifest | 根目录为空时 disabled |
| 持久返回 / `WorkflowBackButton` | Ready | 进入 11 | 不撤销已封存包 |
| 持久下一步 / `WorkflowNextButton` | 封存成功 | 进入 13 | 与历史按钮共用门禁 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 封存中，导航与重复保存 disabled |
| Empty | 无 QcReady run；无图、无包清单成功标记 |
| Ready | Packaged，路径和七项实际工件完整 |
| Warning | 科研确认边界或历史中存在损坏包 |
| Error | 写入、冲突或哈希校验失败；保留 QcReady 可重试 |
| Disconnected | Live 未连接不影响 Mock 封存 |
| Permission denied | 显示精确输出根和权限错误；不创建部分成功包 |

## 导航、持久化与审计

- 每个 run 只允许一个非覆盖结果目录；目录冲突拒绝。
- 审计：`PACKAGE_SAVE_STARTED`、`PACKAGE_SAVED`、`PACKAGE_SAVE_FAILED`、`RESULT_PATH_OPENED`、`RESULT_PATH_COPIED`、`HISTORY_OPENED`。

## 可访问性

- 工件清单提供文件名、状态和校验结果文本。
- 复制成功通过状态文本反馈。
- disabled 外部分析有 tooltip 和 accessibleDescription。
