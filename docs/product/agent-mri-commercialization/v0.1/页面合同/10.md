# 10 Mock 输出与标准处理

## 目的与边界

把当前 run 的合法 Mock 输入绑定到现有 Mock 重建资产，依次完成来源记录、Mock 处理和标准结果准备。不得称为已验证 k-space，不得调用新算法或真实代理。

## 进入与离开

- 进入：09 同一 run 的 Mock 执行完成，状态为 Processing。
- 返回：只能返回 08 重新开始新 run；不能返回 09 伪装活动运行。
- 前进 11：Mock 资产读取和处理成功后点击 `CompleteMockProcessingButton` 或模型自动进入 Reconstructed。

## 信息层级与数据来源

1. run/snapshot 身份和 Mock 来源记录。
2. 处理阶段：输入绑定、资产读取、标准 Mock 结果、QC 等待。
3. 预览只来自项目现有合法 Mock 资产，标明 `MOCK`。
4. 不出现“真实 RAW 已保存”“已验证 k-space”等无证据文案。

## 可交互控件

| 控件 / objectName | 前置条件 | 可见结果 | 禁用原因、确认与撤销 |
|---|---|---|---|
| 完成 Mock 处理 / `CompleteMockProcessingButton` | Processing 且资产读取成功 | 状态进入 Reconstructed，进入 11 | Loading/Error 时 disabled 并解释 |
| 重试处理 / `RetryMockProcessingButton` | 状态 Failed 且输入仍合法 | 重新读取同一 Mock 资产，记录重试事件 | 不改变 run/snapshot |
| 持久返回 / `WorkflowBackButton` | Processing/Failed | 提示本 run 将保持失败/取消，确认后回 08 | 不回 09 |
| 持久下一步 / `WorkflowNextButton` | Reconstructed | 进入 11 | 未完成时 disabled |
| 预览卡片 | 任意 | 不可点击 | 只读，不伪装操作 |

## 页面状态

| 状态 | 可见表现 |
|---|---|
| Loading | 显示真实的 Mock 处理阶段和进度，不显示最终图/QC |
| Empty | 无合法 run 时不显示处理完成状态 |
| Ready | Reconstructed 后可进入 11 |
| Warning | 明确“Mock 资产处理，非设备 RAW/k-space 验证” |
| Error | 资产缺失/不可读时 Failed，无图/QC，显示重试 |
| Disconnected | Live 未连接不影响 Mock 处理 |
| Permission denied | 资源不可读按 Error；结果根不可写只影响 12 封存 |

## 导航、持久化与审计

- 处理产物在封存前驻留内存；不写真实 RAW。
- 审计：`MOCK_PROCESSING_STARTED`、`MOCK_ASSET_BOUND`、`MOCK_RECONSTRUCTED`、`MOCK_PROCESSING_FAILED`、`MOCK_PROCESSING_RETRIED`。

## 可访问性

- 阶段进度使用文字与进度条双重表达。
- Error 中包含资产逻辑名称，不暴露不必要的系统内部细节。

## 关联验收

`MRACC-PROC-001`、`MRACC-PROC-002`、`MRACC-ERR-001`、`MRACC-SRC-001`。
