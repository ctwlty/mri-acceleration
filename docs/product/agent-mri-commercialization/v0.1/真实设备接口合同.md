# Agent-MRI v0.1 真实设备接口合同

## 当前结论

- 真实设备能力阶段：`DESIGNED`。
- 默认可见流程状态：`LIVE: BLOCKED`。
- 本轮允许的可执行数据源只有 `MOCK`。
- 仓库已有 `DeviceBridge`、`MriSdkLoader`、`--auto-connect` 和 fake SDK 测试入口，不等于真实设备能力已经 `TARGET-ENV-VERIFIED` 或 `RELEASE-GATE-PASSED`。
- 本合同不授权加载 SDK、连接设备、写参数文件、调用 Run/Abort、调用 eggcontrollerV2 或生成真实 RAW。

## 未来真实运行的唯一放行条件

未来一次真实运行必须在同一参数快照和同一人工授权作用域内，同时具备以下七项可审计证据。任一项缺失、过期、冲突或为 `unknown`，结论均为 `BLOCKED`。

| 门禁 | 必须冻结的证据 | 失效条件 |
|---|---|---|
| SDK 身份 | DLL 绝对路径、文件大小、SHA-256、架构、导出接口版本、加载时间 | SDK 重载、文件变化或身份不完整 |
| 设备 IDLE | 设备身份、连接结果、温度、ScanStatus、读取时间 | 断连、状态非空闲、读取超时或来源不明 |
| 协议与横断位映射 | 协议标识、参数文件身份、横断位方向、Read/Phase、覆盖与切片映射 | 协议、方向或规划发生变化 |
| 参数快照 | 唯一 snapshot ID、全部运行参数、协议链、输出约束 | 任一参数编辑或快照身份冲突 |
| 隔离输出 | 新建且可写的绝对目录、目录 owner、运行前清单 | 目录不可写、与历史运行共用或会覆盖已有结果 |
| 唯一 Run owner | 当前进程身份、PID、启动时间、互斥所有权 | 发现第二个控制进程、owner 丢失或进程身份变化 |
| 单次人工授权 | 操作者、授权时间、绑定 run ID/snapshot ID、只允许一次 | 超时、身份变化、运行完成/失败/取消或任何门禁失效 |

## 未来接口边界

1. UI 只提交不可变的真实运行请求；请求包含七项门禁证据、唯一 run ID 和 snapshot ID。
2. 设备适配层必须在副作用前再次验证请求，不能信任按钮 enabled 状态。
3. 只有所有门禁为已证实且人工授权与本次 run/snapshot 完全一致时，适配层才可进入真实执行。
4. 真实执行开始后，其他窗口、进程和自动恢复逻辑不得成为第二个 Run owner。
5. 正常完成不调用 Abort；异常或超时的 Abort 规则属于未来独立安全验收，不在 v0.1 实现。
6. 真实 RAW、重建图、QC 和结果包必须绑定同一 run/snapshot；Mock 或历史数据不得冒充真实同次结果。

## 当前 UI 行为

- `LoadSdkButton`、`ConnectDeviceButton`、`RealPrecheckButton`、`RealRunButton` 均 disabled。
- 每个真实入口的 tooltip 和可访问性说明统一列出七项缺失门禁。
- `HistoricalRaw` 不可执行，明确显示“受控解析与来源绑定尚未建立”。
- `LiveBlocked` 不生成 run ID、snapshot ID、进度、图像、QC 或结果包。
- 无参数启动不得传入 SDK、自动连接或设备控制参数。

## 发布判定

- Mock 软件闭环可独立按 v0.1 验收合同判断。
- 真实设备能力在七项门禁没有完成目标环境验收前始终为 `NO-GO / BLOCKED`。
- 若未来实施真实设备能力，必须另立版本化合同、目标环境证据和单次人工授权，不得修改本合同中的默认阻断语义来绕过验收。
