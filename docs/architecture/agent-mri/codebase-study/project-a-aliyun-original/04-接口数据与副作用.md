# Project A｜04 接口、数据与副作用

本页只读取 `80b5d85` 提交树。

## DLL 加载与导出

- Windows 加载器：`LoadLibraryA` + `GetProcAddress`。证据：`80b5d85:client/src/app/MriSdkLoader.cpp:21-54,263-315`。
- 必需导出：`Init`、`ConfigFile`、`SetOutputPath`、`SetParameterFile`、`SetSaveMode`、`SetSystemSel`、`SetChannelValid`、`SetParameter`、`SetTxCenterFre`、`SetChannelValue`、`SaveParameterFile`、`Run`、`Abort`、`CloseSys`、`GetTotalScanNo`、`GetCurrentScanNo`、`GetTemperature`、`GetConnectStatus`，以及 `ScanStatus`/`ScanCompleted` 至少一个。
- **UNKNOWN**：调用约定、ABI、返回码和签名是否与目标 `mridll.dll` 完全一致；A 没有 binary identity 或 fake SDK 证据。

## 调用顺序与副作用

| 入口 | 调用/输出 | 副作用 |
|---|---|---|
| `MainWindow::handleLoadSdk` | 选择 DLL → `DeviceBridge::loadSdk` → initialize | 加载 DLL；调用 Init/Config/输出/参数/保存模式 |
| `MriSdkLoader::initialize` | `Init → ConfigFile → SetOutputPath → SetParameterFile → SetSaveMode` | 影响 SDK 会话和输出配置 |
| `DeviceBridge::connectDevice` | Real 模式直接标“已连接”并读取温度 | 无真实建链/连接码门禁 |
| `DeviceBridge::dryRunScene` | `ProtocolMapper::generateDryRun` | 创建 `applicationDir/dry_run_params/*.dryrun.par` |
| `MriSdkLoader::prepareForScene` | 固定 SetSystem/Channel/TR/Tx/channel value + SaveParameterFile | 写 SDK 参数并请求保存 `scenario_nmr.par` |
| `MriSdkLoader::run` | `Run()` | 真实设备副作用，库存模板 HOLD 阻断 |
| `MriSdkLoader::abort` | `Abort()` | Real mode 可达，无运行态/授权检查 |
| `MriSdkLoader::shutdown` | `Abort → CloseSys` | 析构时 Real mode 无条件执行 |

证据：`80b5d85:client/src/app/MriSdkLoader.cpp:107-151,201-247`、`DeviceBridge.cpp:24-143`。

## 参数数据事实

`prepareForScene(const SceneTemplate&)` 实际忽略传入的场景，固定设置：system 3、channel `255`、`viewBlock=1`、`TR=500`、8 路 Tx=50、3 个 channel=1000，并请求保存 `scenario_nmr.par`。setter 与保存调用的返回值被忽略。证据：`80b5d85:client/src/app/MriSdkLoader.cpp:201-223`。

DRY_RUN 文件包含映射预览，并明确写 `realRun=HOLD`、`writeToSdk=false`；它没有把 whitelist 写入 SDK。证据：`80b5d85:client/src/app/ProtocolMapper.cpp:99-164`。

## 失败与恢复边界

- DLL 不存在/导出缺失：回退 Demo 且 `load()` 返回成功；真实失败和 Demo 可用被合并。
- initialize 部分失败：无 CloseSys rollback，仍可通过“连接”进入“已连接”文案。
- reload：先 `FreeLibrary`，没有先 `shutdown()`，已有会话的关闭语义未保护。
- Run prepare/Run 失败：只写错误和日志；没有恢复或自动 Abort。
- Abort：无 acknowledgement、重试、超时和停止确认。
- **UNKNOWN**：未运行/部分初始化时 Abort 是否安全；SDK 调用卡死时如何恢复。

## 数据与持久化

- 输入：编译时 SceneCatalog、UI 选择、外部 DLL/init/par/output 路径。
- 内存输出：标签、日志、静态指标、SDK 状态字符串。
- 磁盘输出：DRY_RUN `.par`；SDK 自己可能写 `scenario_nmr.par`/RAW，但 A 没有接收和验证代码。
- 不存在：manifest、hash 绑定、RAW→图像、QC、结果包、历史、审计事件。
