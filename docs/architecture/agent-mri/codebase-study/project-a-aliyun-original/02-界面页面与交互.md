# Project A｜02 界面、页面与交互

本页只读取 `80b5d85` 提交树。

## 信息架构

Project A 没有多页路由。整个产品是一个持续存在的 `QMainWindow`：

```text
Header
└─ QSplitter 三栏
   ├─ 左：场景 / 对象 / 搜索 / 模板 / 7 个动作按钮
   ├─ 中：6 节点文字操作链 + 2×2 暗色占位视窗
   └─ 右：4 个静态指标卡 + 参数预设 / SDK诊断 / 日志 Tab
Footer：连接、传输、异常、扫描和温度文本
```

证据：`80b5d85:client/src/app/MainWindow.cpp:58-87,143-438`。

## 可见控件与真实反馈

| 控件 | 信号/槽 | 实际可见结果或副作用 |
|---|---|---|
| 一级场景 | `currentIndexChanged → handlePrimarySceneChanged` | 重建对象列表，默认第一对象 |
| 检测对象 | `currentIndexChanged → handleTargetChanged` | 通过 `populateTemplatesForSelection()` 过滤模板列表，默认第一模板 |
| 模板搜索 | `textChanged → handleTemplateSearchChanged → populateTemplatesForSelection` | 重建列表；无结果时详情可能回退目录第一模板 |
| 模板列表 | `currentRowChanged → handleSceneChanged` | `applyScene()` 更新标签、参数、操作链、静态指标 |
| 加载 SDK | `clicked → handleLoadSdk` | 文件选择；同步 load + initialize |
| 一键建链 | `clicked → handleConnect` | Real 模式直接标“已连接”并读取温度；不是 SDK 建链命令 |
| 校准向导 | `clicked → handlePrecheck` | 只追加三条日志 |
| DRY_RUN | `clicked → handleDryRun` | 写 `.dryrun.par` 并更新日志/标签 |
| Demo 采集 | `clicked → handleStart` | Demo 刷新静态指标；Real + HOLD 被阻断 |
| 暂停 | `clicked → handlePause` | 只修改 UI 状态文本 |
| 急停 | `clicked → handleAbort` | Real mode 可直接调用 DLL `Abort` |

证据：`80b5d85:client/src/app/MainWindow.cpp:201-246,521-703,769-859`，`80b5d85:client/src/app/DeviceBridge.cpp:50-143`。

## 导航事实

- **VERIFIED FACT**：源码没有 `QStackedWidget`、Wizard、Next、Back 或 page-state；六节点是 `setOperationChain()` 写入的展示标签，不是路由。
- **VERIFIED FACT**：三级选择的真值分散在两个 `QComboBox` 和一个 `QListWidget`。
- **VERIFIED FACT**：`handleResume()` 存在，但没有 Resume 按钮或 signal；Pause 按钮只连接 `handlePause()`。证据：`80b5d85:client/src/app/MainWindow.cpp:218-220,245,690-698`。
- **VERIFIED FACT**：`m_sceneTarget`、`m_sceneSequence`、`m_sceneStepA/...` 只声明未构造，`applyScene()` 中的空指针保护使对应更新没有可见消费者。证据：`80b5d85:client/src/app/MainWindow.h:65-72`、`MainWindow.cpp:769-794`。

## 页面状态

- Loading：没有专用状态。
- Empty：搜索无结果时列表为空，但 `currentScene()` 可回退第一模板。
- Ready：以标签文本呈现，不是类型化状态。
- Warning/Error：主要写日志和 SDK error 标签。
- Disconnected/Permission denied：没有独立页面状态。
- 确认/撤销：没有工作流级确认、撤销或脏草稿提示。

## 推断与未知

- **INFERENCE（高置信）**：六节点操作链和四视窗是展示骨架，不能据此证明六阶段任务可执行。
- **INFERENCE（高置信）**：搜索无结果时“筛选条件”和“显示详情”可能分裂，因为 `currentScene()` 回退目录首项。证据：`80b5d85:client/src/app/MainWindow.cpp:596-628,833-842`。
- **UNKNOWN**：目标 Windows DPI、中文字体、动态 `class` 属性重绘和键盘可访问性；A 没有截图/辅助功能验收证据。
