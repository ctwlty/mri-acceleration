## 实际业务链

```text
选择模板
  → 可选 Load + Init
  → “连接”（只投影状态）
  → “预检”（只写日志）
  → DRY_RUN（可写参数预览）
  → Start
       ├─ Demo：刷新内存指标/状态
       ├─ Real + HOLD：拒绝 Run
       └─ Real + 非 HOLD：写固定 SDK 参数 → Run
  → Pause/Resume：只改 UI 字符串
  → Abort：直接调用适配器
```

## 门禁与状态转移

- **VERIFIED FACT**：全部库存模板的 `runGate=HOLD`、`adaptationStatus=待设备适配`、`parameterStatus=开发预设`、`sdkMappingStatus=待序列字段映射`。证据：`80b5d85:client/src/app/SceneCatalog.cpp:23-72,75-211`。
- **VERIFIED FACT**：因此库存 UI 的 Real Start 不会到 `Run`；但代码中的非 HOLD 分支真实存在。
- **VERIFIED FACT**：`MriSdkLoader` 只有 `Mode { Demo, Real }` 模式枚举；没有领域/扫描工作流状态机、预检凭证、单次 run owner、扫描轮询、完成回调、RAW 完成判据或错误恢复状态。证据：`80b5d85:client/src/app/MriSdkLoader.h:15-18`。
- **VERIFIED FACT**：`scanStatus()`、`scanCompleted()`、`connectStatus()` 有实现但无生产调用者；Run 后只读取一次 current/total。证据：`MriSdkLoader.cpp:153-198`、`DeviceBridge.cpp:113-115`。
- **VERIFIED FACT**：`fetchDemoFrame()` 生成 128 点模拟数据，但在 `client` 内无调用者。证据：`MriSdkLoader.cpp:250-260`。

## 同步、超时、取消、恢复

| 维度 | As-Is |
|---|---|
| 同步/异步 | GUI、DLL、文件调用全部在 GUI 线程同步执行 |
| 超时 | 无 |
| Pause/Resume | 只修改字符串，不控制 SDK |
| Cancel | 无任务级取消；Abort 是设备命令而非领域取消 |
| 错误 | 字符串/日志；无统一 Fault |
| 恢复 | 无重试、恢复、重启续接或部分 Init rollback |

## 事实、推断、未知

- **VERIFIED FACT**：设计文档中的“预检后允许 Run”“结果保存/交接”没有对应状态/实体，不能当作 A 的已实现行为。

- **UNKNOWN**：任务、样品、一次扫描身份、结果归属、失败重试和恢复语义；源码没有这些概念。
- **UNKNOWN**：模板参数对真实设备是否合法；`80b5d85:docs/scenario-nmr-017t-parameter-presets.md` 明确其为开发预设。
