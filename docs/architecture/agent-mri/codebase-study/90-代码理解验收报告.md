## 证据等级

- **VERIFIED**：固定 Git 对象、当前只读文件、可复核哈希或原始日志直接支持。
- **DOC-ONLY**：只有历史文档声称，缺少不可变源码、构建或运行绑定。
- **INFERENCE**：由多个已验证事实推导，但不是直接运行事实。
- **UNKNOWN**：现有证据不足，或需要厂家合同、历史证据包或受控实机才能确认。
- **CONTRADICTED**：直接证据与既有说法、另一提交或当前状态冲突。

引用采用 `<commit>:<path>:<line>`；行号不稳定时使用 `<commit>:<path>::<symbol>`。外部可变目录使用绝对路径、长度和 SHA-256，不把它提升为 Git 事实。
