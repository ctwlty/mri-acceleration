# Project B｜03 业务流程与状态

## 1. 四套状态模型的演进

### B0：原生 SDK 会话

`c236e00:client/src/app/MriSdkTypes.h::MriSdkSessionState` 定义 `Unloaded/Loaded/Initializing/Ready/Scanning/Stopping/Fault/Closed`。`DeviceBridge` 持有 session、config、轮询 timer、扫描/停止/RAW settle 计时器和扫描前 RAW 快照。

正常链：

```text
loadSdk → Loaded
connectDevice/initialize → Initializing → Ready
startScan → prepareScan → Run → Scanning
poll active 1/2/4
active → idle 0/3 → 等待新增或更新且非空 RAW → Ready
异常 -1/5/6 或 timeout → Abort 一次 → Stopping/Fault
```

证据：`c236e00:client/src/app/DeviceBridge.h`、`c236e00:client/src/app/DeviceBridge.cpp::loadSdk/connectDevice/startScan/refreshStatus`、`c236e00:client/src/app/MriSdkLoader.cpp::initialize/prepareScan`。

### B1-R：运行时身份与预检凭证

`c77aeb4` 在上述会话外增加 runtime identity proof、`ExecutionGate { Hold, VerifiedBaseline }`、`PrecheckTicket`、输出可写和 idle/status/连接核验。配置/模式/会话变化会使 ticket 失效。

**VERIFIED FACT**：这套 gate 只在 B1-R 分支，不在当前 `33be`。

### B1-P：外部自动化进程状态

`8e4ad0b:client/src/app/EggControllerProcess.h` 独立持有 `QProcess`、stdout buffer、待交付工件和 terminal-signal flag。它通过 JSONL `stage/error/result` 驱动 UI；不共享 `DeviceBridge` 状态机。

### B2 当前：Mock 领域状态

`91343be:client/src/app/MockWorkflow.h` 定义：

```text
Empty → Prepared → Running ⇄ Paused
Running/Paused → Cancelled
Running → Processing → Reconstructed → QcReady → Packaged
Running/Paused/Processing/Reconstructed/QcReady → Failed
Failed（有 run/snapshot）→ Processing
```

同时有 `DataSourceKind { Mock, HistoricalRaw, LiveBlocked }`；当前只有 Mock 可运行，其他值返回阻塞原因。

## 3. 状态所有权

| 状态/数据 | 真正所有者 | 镜像或重复 |
|---|---|---|
| SDK 会话 | `DeviceBridge` | MainWindow 标签/按钮 |
| Mock 领域状态、run/snapshot、审计、QC metadata | `MockWorkflow` | `m_mockRunActive`、progress/paused 等 UI 镜像 |
| 当前页面 | `MainWindow::m_workflowStep` | 两个 `QStackedWidget` 当前 index |
| 场景/对象/模板 | 左栏控件 + `m_catalog` | 页 02 radio/卡片、硬编码 snapshot 文案 |
| 定位几何 | `LocalizationPlannerView` 属性 | snapshot 在 start 时复制 |
| 准备/协议/定位确认 | 三个 `MainWindow` 布尔 | 页面控件视觉状态 |
| 成功历史 | 磁盘结果包 manifest | 当前内存 Packaged 决定历史入口是否开放 |
| automation | `EggControllerProcess` | 当前只有配置，无生产 start 边 |

## 4. 异步、超时、取消与恢复

| 路径 | 执行模型 | 超时/取消/恢复 |
|---|---|---|
| SDK | DLL 同步 + DeviceBridge timer 轮询 | 扫描/停止/RAW settle 外层超时；异常/超时 Abort；单次 DLL 调用无 timeout |
| eggcontroller proxy | `QProcess` 异步 | 8e4 无总 timeout/显式取消；当前生产 UI 不启动 |
| Mock acquisition | GUI 单次 3.2 秒 timer | Running/Paused 可取消；3.2 秒是演示完成点，不是错误 timeout |
| Mock processing/QC/package/history | GUI 线程同步 | 无取消/timeout；大文件/大历史可能阻塞，尚未运行验证 |

- **VERIFIED FACT**：Cancelled/未封存 Failed 只在内存；重启不恢复。
- **VERIFIED FACT**：`retryProcessing()` 对任意拥有 run/snapshot 的 Failed 开放，模型不保存失败阶段。
- **VERIFIED FACT**：QA `setMockWorkflowStep()` 可以把 Empty 模型直接展示在任意页；页面号不是领域状态的强约束。
- **INFERENCE（高置信）**：页面、UI 镜像与领域状态不是单一真值源，跨页返回/直接跳页时存在状态分裂风险。

## 5. 当前外部副作用边界

- 默认 Mock 链：不调用 SDK/Run/Abort或 eggcontroller；开始前可能对 output root 做可写探针，成功封存会写结果包。
- CLI `--auto-connect`：真实 DLL load/init 可达。
- `mri_sdk_verify --scan`：独立真实 Run 路径可达，但不属于 GUI 页面导航。
- automation CLI：当前只配置，不 start；8e4 阶段曾可 start。
