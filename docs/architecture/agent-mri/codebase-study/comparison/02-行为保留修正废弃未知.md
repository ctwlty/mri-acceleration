# Comparison｜02 行为保留、修正、废弃、未知

## 分类含义

- **PRESERVE**：A 的外部行为在 B 中仍可识别地存在。
- **CORRECT**：B 已改变 A 的行为，且源码意图表现为缺陷修正/加固。
- **RETIRE**：B 已不再暴露或不再调用 A 的行为。
- **UNKNOWN**：版本事实不足以判断产品意图，或多个分支给出不同答案。

这些标签是 As-Is 变更分类候选，不是 To-Be 决策。除纯事实性的“已在代码中改动/移除”外，所有 CORRECT/RETIRE 是否应成为最终产品规则都标为“待 Grill”。
