场景化核磁共振控制台原型

科研 / 教学方向的 Windows C++ 客户端概念稿，重点是把设备控制链做成模板化流程。

产品定位

把谱仪从“函数驱动的设备控制”变成“场景驱动的科研/教学流程”。系统不直接暴露一堆散参数，而是先选场景，再按检测对象加载模板，随后自动串起连接、校准、序列、采集、图像处理和分析指标。

核心流程

  • 场景选择 -> 检测对象确认 -> 设备连接与硬件预检
  • 序列模板装载 -> 中间操作 A/B -> 采集与状态监控
  • 图像处理 -> 指标分析 -> 保存与复盘

模板字段

场景教学演示 / 科研试验 / 对照扫描
检测对象组织切片 / 标准样本 / 对照体模
序列选择模板化序列 + 参数包
中间操作校准 / 匀场 / 预加重 / 通道检查
图像处理滤波 / 重建 / ROI / 标签
分析指标SNR / 均匀性 / 峰值 / 面积
